# Alloy-kt

Kotlin components for [alloy-framework](https://github.com/alloy-framework/alloy).
This library and alloy-framework are still in development, so expect breaking changes.

## Requirements

- yarn
- Node.js 25+

## Usage

See [docs](https://ty-v1.github.io/alloy-kt/guides/getting-started/).

## Build

1. Clone the repo

   ```shell
   git clone git@github.com:ty-v1/alloy-kt.git
   ```

2. Install dependencies

   ```shell
   yarn
   ```

3. Build with yarn

   ```shell
   yarn build
   ```

## Development

- Run tests

  ```shell
  yarn run test
  ```

- Run eslint

  ```shell
  yarn run lint:fix
  ```

- Format code

  ```shell
  yarn run format
  ```
